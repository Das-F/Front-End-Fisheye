# 🐟 Fisheye — Projet Front-End (Site de photographes)

**Fisheye** est un projet du parcours Développeur Front-End OpenClassrooms (Projet 6).  
Il s'agit d'une interface web interactive pour présenter un photographe et ses galeries, avec tri, filtrage et lightbox.

---

## 🎯 Objectifs du projet
- Créer une interface dynamique et responsive pour afficher des photographes et leurs médias.
- Appliquer les bonnes pratiques de code front-end : modularité, lisibilité, accessibilité.
- Manipuler le DOM et les événements JavaScript.
- Gérer des données JSON pour un affichage dynamique.

---

## 📂 Technologies principales
- **HTML** : structure des pages (index, page photographe)  
- **CSS** : styles, mise en page responsive (Flexbox, Grid, Media Queries)  
- **JavaScript** : tri, filtrage, affichage dynamique, modales/lightbox  

---

## 🚀 Installation & utilisation
Cloner le dépôt :  
```bash
git clone https://github.com/Das-F/Front-End-Fisheye.git
```

✅ Fonctionnalités clés
Affichage dynamique des photographes et médias depuis JSON
Tri interactif (popularité, date, titre)
Lightbox / modal pour visualisation des médias en plein écran
Design responsive (mobile, tablette, desktop)
Interface fluide avec transitions agréables
Respect partiel des normes d’accessibilité

⚠️ Limites & pistes d’évolution
Données statiques (pas de backend ni de persistance)
Améliorations possibles :
Intégrer une API pour données dynamiques
Ajouter une page d’administration
Optimiser les performances (lazy loading)
Ajouter des tests unitaires et fonctionnels
Améliorer l’accessibilité (ARIA, navigation clavier)

🎓 Objectifs pédagogiques visés
Manipuler le DOM et gérer les événements JavaScript
Gérer des données JSON côté front-end
Créer un site responsive sans framework serveur
Appliquer les bonnes pratiques de code (modularité, lisibilité, maintenance)
